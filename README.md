# Starbie - Motion-Controlled Digital Pet

Starbie is a custom macropad PCB I designed for Half-lifes week 1.

I built this project to learn how to design a complete PCB, route connections, and place components properly in KiCad.

## Features:

* Custom routed PCB layout designed from scratch
* Fits mechanical key switches
* Built-in USB-C interface for power and data
* Compact macropad design

## What it is and why I made it:
Starbie is a custom-designed motion-controlled digital pet, built to function like a desktop Tamagotchi. I created this project to learn end-to-end PCB design, from drawing custom schematics and routing traces in KiCad to laying out physical components on a unique star-shaped board.

## How it works:
The board integrates a microcontroller (XIAO-ESP32-C3) connected to push buttons, indicator LEDs, and headers, allowing it to process user inputs and run digital pet logic.
