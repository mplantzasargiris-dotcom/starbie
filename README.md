# starbie
<img width="3840" height="2160" alt="image" src="https://github.com/user-attachments/assets/0b5c60e7-ea86-482d-b718-f334aa2424ef" />

Starbie is a custom macropad PCB I designed for Half-lifes week 1.

I built this project to learn how to design a complete PCB, route connections, and place components properly in KiCad.

## Features:

* Custom routed PCB layout designed from scratch
* Fits mechanical key switches
* Built-in USB-C interface for power and data
* Compact macropad design

## PCB Design:

Everything was designed and routed in KiCad, focusing on clean trace routing and proper component layout for safe soldering and operation.
